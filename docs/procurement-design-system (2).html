02 · Foundation
Semantic Color Usage
How each color token maps to a UI role. Use these as your decision guide — never pick colors by shade alone, always by purpose.
Surfaces & Backgrounds
Page Background
--neutral-100 · #f3f4f6
The outermost page canvas. Used on <body>. All content sits on top of this.
Global
Surface / Card Background
--white · #ffffff
Cards, modals, panels, table rows, form inputs. The primary elevated surface.
Cards
Subtle Surface
--neutral-50 · #f9fafb
Table headers, card footers, read-only fields, accordion bodies. One step above white.
Recessed
Dark / Navigation Background
--primary-900 · #0a1628
Sidebar nav, top header bar, dark panels. The brand's darkest surface.
Nav
Tinted / Selected Surface
--primary-50 · #eff6ff
Selected table rows, active filter chips, info section boxes. Indicates selection or focus.
Selection
Primary & Brand Colors
Primary Action
--primary-600 · #1a4480
Primary buttons, active nav item highlight, links in tables, key interactive elements.
Primary
Primary Hover
--primary-500 · #2563b0
Hover state for primary buttons. Also used for sparklines and progress bars.
Hover
Primary on Dark
--primary-400 · #3b82d4
Active sidebar nav indicators, focus rings on dark surfaces, links on dark backgrounds.
On Dark
Secondary Brand / Accent
--accent-500 · #0891b2
Gradient pair with primary-500 for logo mark, stat highlights, and decorative accents.
Accent
Text & Typography Colors
Primary Text
--neutral-900 · #111827
Headings, labels, table cell values, modal titles. Highest contrast on white.
Aa
Body Text
--neutral-700 · #374151
Form labels, descriptions, table column content. Standard readable text.
Aa
Muted / Helper Text
--neutral-500 · #6b7280
Placeholder text, form hints, table header labels, timestamps, secondary metadata.
Aa
Disabled / Placeholder
--neutral-400 · #9ca3af
Disabled form inputs, placeholder text, empty state icons, skeleton base.
Aa
Inverse Text (on dark)
--white · #ffffff
Text on primary buttons, nav items, dark surfaces, and colored badges.
Aa
Borders, Dividers & Outlines
Default Border
--neutral-200 · #e5e7eb
Cards, input fields, tables, dividers, modals. The standard separator color.
Default
Stronger Border
--neutral-300 · #d1d5db
Hovered input borders, focused secondary buttons, dropdown menus.
Hover
Focus Border
--primary-500 + shadow-focus
Focused inputs, active tabs, selected elements. Always paired with a focus ring shadow.
Focus
Subtle / Inner Divider
--neutral-100 · #f3f4f6
Row separators inside cards, accordion item dividers, form section breaks.
Subtle
Status & Feedback Colors
Success / Approved
--success-600 · #15803d
Approved POs, positive trends, completed steps, success toasts and alerts.
Approved
Warning / Pending
--warning-500 · #f59e0b
Pending approval, budget near threshold, expiring accreditations, caution states.
Pending
Danger / Rejected
--danger-600 · #dc2626
Rejected POs, expired accreditations, destructive actions, error toasts and alerts.
Rejected
Informational / Draft
--primary-600 · #1a4480
Draft POs, info alerts, neutral status badges, awaiting-action states.
Draft
Neutral / Cancelled
--neutral-400 · #9ca3af
Cancelled or archived records, inactive steps, disabled states, closed items.
Cancelled
